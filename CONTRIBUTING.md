# Contributing

Thank you for helping improve the public companion repository.

## Appropriate contributions

- confirmed typographical corrections;
- broken local-link fixes;
- clearer sample-code comments;
- reproducible defects in the public samples;
- improvements to setup and accessibility documentation.

## Contributions that will not be accepted

- uploads of paid PDF content;
- leaked or employer-confidential interview questions;
- complete answer banks copied from other products;
- personal purchase or payment information;
- broad rewrites that change the product scope without prior discussion.

## Before opening a pull request

1. Open a focused issue or use the content-correction form.
2. Keep the change limited to one subject.
3. Run `python3 scripts/validate_repo.py`.
4. Compile and run the Java sample when it is affected.
5. Explain the evidence for factual corrections.

## Pull-request expectations

A good pull request includes:

- a clear problem statement;
- the exact file and section changed;
- the reason for the correction;
- validation performed;
- confirmation that no paid content was added.
