| Version | Supported |
| --- | --- |

## Reporting a security issue

Do not publish credentials, tokens, personal data, or exploitable details in a public issue.

Send a private report to `weissmann-tobi@gmail.com` with:

- the affected file or sample;
- reproduction steps;
- expected and actual behaviour;
- potential impact;
- a suggested correction when available.

This public repository contains training samples and product documentation. The paid companion project may have a separate security policy inside its own archive.
