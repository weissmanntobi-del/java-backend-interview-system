# Code of conduct

This repository is intended for constructive technical learning.

Participants must:

- communicate respectfully;
- criticise content and code rather than people;
- avoid publishing personal, employer-confidential, or payment information;
- avoid presenting leaked interview material as preparation content;
- provide evidence for factual corrections where possible.

Harassment, discrimination, threats, spam, and deliberate copyright infringement are not acceptable.

Report conduct concerns privately to `YOUR_SUPPORT_EMAIL`.
