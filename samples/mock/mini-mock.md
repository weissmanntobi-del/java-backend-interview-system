# Mini Java backend mock interview

Use a timer. Answer before reading any notes.

## Round structure

| Question | Time | Evaluation focus |
| --- | ---: | --- |
| Explain `HashMap` lookup and collision handling | 4 min | Internals, complexity, edge cases |
| Explain a Spring Boot request from HTTP to database commit | 6 min | Runtime flow and boundaries |
| Diagnose an API whose p99 latency increased after a release | 8 min | Evidence, hypotheses, mitigation |
| Replace deep OFFSET pagination | 6 min | Query shape, index, consistency |
| Design an order-payment workflow with Kafka | 10 min | Idempotency, outbox, failures |

## Scoring rubric

Score each category from one to five:

- correctness;
- structure;
- practical examples;
- production relevance;
- trade-off reasoning;
- response to follow-up pressure.

## Reflection

After the mock, write:

1. What was technically wrong?
2. Which answer was vague despite being correct?
3. Which example came from real experience?
4. Which trade-off did you fail to explain?
5. Which exact resource or topic will you revise next?
